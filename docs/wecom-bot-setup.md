# 企业微信智能机器人：创建与凭证配置

本项目使用企业微信「**智能机器人**」的 **API 模式 + 长连接**。
它不需要公网回调地址，桥接程序主动连接企业微信网关即可。

> 官方文档（以官方为准，后台入口可能随版本调整）：
> - 概述：<https://developer.work.weixin.qq.com/document/path/101833>
> - 开发前必读（创建机器人 / 获取凭证）：<https://developer.work.weixin.qq.com/document/path/101805>
> - 长连接：<https://developer.work.weixin.qq.com/document/path/101463>
> - 接收消息：<https://developer.work.weixin.qq.com/document/path/101834>
> - 官方 Python SDK：<https://github.com/WecomTeam/wecom-aibot-python-sdk>

---

## 1. 前置条件

- 你是企业微信的管理员（或拥有创建应用/机器人的权限）；
- 企业微信已激活（组织架构可用）；
- 手机端能正常收发企业微信消息。

## 2. 创建机器人

1. 电脑浏览器登录 [企业微信管理后台](https://work.weixin.qq.com/)；
2. 顶部/侧边找到 **应用管理**；
3. 在应用列表中找到 **智能机器人**（或「机器人」）入口 → **创建机器人**；
4. 填写：
   - **名称**：如「办公助手」（手机端显示）；
   - **头像**：可选；
   - **可见范围**：建议先只勾选自己，验证后再扩大；
5. 创建完成后进入机器人详情页。

## 3. 开启 API 模式（长连接）

在机器人详情页：

1. 找到 **API 模式**（或「开发者模式 / 连接方式」）；
2. 连接方式选择 **长连接**（WebSocket）；
3. 保存/启用。

> 长连接模式的特点：不用填公网回调 URL，也不需要开放任何入站端口；
> 但必须有设备一直运行桥接，否则机器人离线。

## 4. 获取并保存凭证

在机器人详情页的凭证区域复制：

| 凭证 | 用途 | 注意 |
|---|---|---|
| **Bot ID** | 机器人唯一标识 | 可写入 `config.json` 的 `bot_id` |
| **Secret** | 长连接专用密钥（身份校验） | 等同机器人密码；写入 `config.json` 的 `bot_secret` |

安全要求：

- 不要把 Bot ID / Secret 发到聊天、群、截图、Issue、Git；
- 本仓库 `.gitignore` 已排除 `config.json`，请勿强行提交；
- 如果 Secret 泄露：在机器人详情页 **重置 Secret**，更新配置并重启桥接。

## 5. 消息与推送权限

不同企业微信版本/机器人类型可能需要在管理后台配置或确认以下能力：

- **接收消息**：长连接模式下由 SDK 自动订阅，无需单独配置回调；
- **主动推送**：用于「长任务结果」「任务完成通知」「测试通知」。若收不到主动推送，
  检查该机器人是否具备主动发消息权限（机器人详情页 / 应用权限）；
- **可见范围**：决定谁能给机器人发消息。范围越大，能远程操作电脑的人越多，请谨慎。

## 6. 把凭证填进项目

```powershell
copy config.example.json config.json
notepad config.json
```

```json
{
  "bot_id": "你的 Bot ID",
  "bot_secret": "你的 Secret",
  "engine": "auto"
}
```

> 当前版本的 Bot ID / Secret **只从 `config.json` 读取**；云服务器部署时请用
> `chmod 600 config.json` 收紧权限。
> DeepSeek API Key 既支持 `config.json → api.api_key`，也支持环境变量 `DEEPSEEK_API_KEY`。

## 7. 验证连接

启动桥接后看日志：

```text
认证成功，机器人已在线 ✅（在手机企业微信里给它发消息即可）
```

常见失败原因：

| 日志/现象 | 原因 | 处理 |
|---|---|---|
| `认证失败` / 401 | Bot ID / Secret 错误、已重置、复制带空格 | 重新复制、确认无空格；重置后重启 |
| 一直重连 | 同一机器人已有其它长连接（云+本地同时开） | 只保留一份桥接 |
| 手机收不到欢迎语 | 可见范围不含你 / 未在会话里 | 检查可见范围，主动发一条消息 |
| 主动推送收不到 | 机器人无主动推送权限 | 管理后台确认权限；或先只用流式回复 |

## 8. 常见问题

**Q：能不能不用企业微信，用个人微信？**
不建议。个人微信没有官方机器人长连接能力，只能靠模拟客户端（抢鼠标/易封号/易碎），
本项目有意不采用该路线。

**Q：同一个机器人能否多处部署？**
不能。同一个 Bot ID 同时只允许一条长连接；云端与本地同时开会互相踢下线。
需要「电脑关机也能回」时，用 [云端部署](cloud-deploy.md) 并在两者间切换。

**Q：机器人只能企业内部用吗？**
智能机器人面向企业内部，默认仅可见范围内的成员可对话。对外部用户开放需谨慎评估安全风险。
