# 常见问题（FAQ）

## 概念与定位

**Q1：这算不算「微信机器人」？**
不算个人微信机器人，用的是**企业微信官方智能机器人**的长连接能力，合规、不碰客户端、不需要公网回调地址。

**Q2：它和「远程桌面」有什么区别？**
远程桌面是你手动操作电脑；本项目是你**发一句话**，由电脑上的 AI 执行端（DSH）替你干活，
适合「让它跑命令/整理文件/生成文档并回传」这类任务，不需要实时盯屏幕。

**Q3：必须装 DeepSeek Harness 吗？**
想让它**真操作电脑**必须装（DSH 是执行端）；只想**纯聊天**可以不装，配置 DeepSeek API Key 即可。
云端部署（无 DSH）只能纯聊天。

**Q4：可以用个人微信吗？**
不建议、不支持。个人微信没有官方机器人通道，只能模拟客户端，抢鼠标、易封号、脆弱。

## 部署与运行

**Q5：电脑必须一直开着吗？**
是的。企业微信长连接需要有一台设备常开跑桥接；电脑关机 = 机器人离线，任何本地代码都绕不过。
想关机也能回，用云服务器/旧电脑常驻（只能纯聊天，见 [cloud-deploy.md](cloud-deploy.md)）。

**Q6：能不能同时在本机和云端跑？**
不能。同一 Bot ID 只允许一条长连接，会互相踢下线。

**Q7：需要公网 IP / 端口映射 / 内网穿透吗？**
不需要。桥接主动外连企业微信网关（出站 443），无需入站。

**Q8：为什么每次启动要等 30~60 秒？**
企业微信认证 + DSH 探测需要时间；慢机器/慢 U 盘会更久。看到日志「认证成功」即上线。

**Q9：可以放 U 盘运行吗？**
可以，整个文件夹可搬。但**运行环境建议放本地盘**（`setup-local-venv.cmd`），
U 盘只放代码/配置/数据；拔盘前先 `stop.cmd`。

**Q10：换电脑/C 盘还原后怎么办？**
`setup.cmd` → `check.cmd` → `start.cmd` → 重新注册开机自启。凭证不用重新注册，
`config.json` 有备份恢复即可。

## 使用

**Q11：支持语音吗？**
支持。企业微信会先把语音转成文字再下发；识别为空时会提示重发。

**Q12：支持发图片/文件给机器人吗？**
当前处理文字、语音、图文混排中的文字；图片/文件消息暂不支持（会提示）。

**Q13：怎么让它把电脑上的文件发给我？**
DSH 模式下说「把 `<路径>` 发我」；它会先上传再发文件卡片（≤50MB）。
API 模式不能发文件（安全设计）。

**Q14：任务太长了怎么办？**
可以随时 `/stop`（或说「停止当前任务」）；长任务每 45 秒刷新进度，
超过 10 分钟的结果会自动改主动推送。

**Q15：为什么回答一半变成「还在处理中」？**
说明执行端还在跑（DSH 任务可能很慢）。等结果或 `/stop`；可用 `/status` 看当前任务。

**Q16：为什么有时回答是「电脑端 DSH 没开…」？**
`engine=auto` 时 DSH 不可用会自动降级到 API 纯聊天；打开 DSH 等十几秒后再发即可恢复。

**Q17：多个同事同时用会怎样？**
每个聊天/用户独立会话；但 DSH 执行端是**全局串行**的（一次跑一个任务），
多人同时发任务会排队。建议小范围使用。

**Q18：能改机器人名字/头像吗？**
可以，在企业微信管理后台的机器人详情页改，与代码无关。

## 安全

**Q19：`config.json` 能提交到 Git 吗？**
**绝对不能**。里面有机器人 Secret 和 API Key；本仓库已 `.gitignore`。
泄露后立即重置 Secret、删除重建 API Key。

**Q20：`dsh.auto_approve=true` 安全吗？**
它会把 DSH 默认权限设为 `danger-full-access`（新会话免审批），等于给远程任务全权限。
自己可控的环境可用（为了无人值守）；安全敏感请设 `false`，任务会在电脑上等人工批准。

**Q21：别人拿到我的机器人就能操作电脑？**
能给他发消息的人 = 能下指令。请把机器人可见范围限制为可信成员；
不要把它开放给外部人员。

**Q22：日志能直接发到 Issue 吗？**
不能直接发。日志含聊天内容摘要与 `chat=` 标识，请先脱敏（删掉 Secret/Key/聊天/文件名/用户标识）。

## 开发与排障

**Q23：为什么改了 `config.json` 有的生效有的不生效？**
只有 `api.*` 热加载；`engine`/`dsh.*`/`reply.*` 需要重启。见 [configuration.md](configuration.md)。

**Q24：`check.cmd` 说 DSH 离线，但 DSH 明明开着？**
DSH 刚重启端口会变、或正在忙；等十几秒重试。桥接会自动发现端口。
若一直不行，看 [troubleshooting.md](troubleshooting.md) 第 3 节。

**Q25：报错 `846608` 是什么？**
企业微信流式消息 10 分钟过期错误码。代码已自动改主动推送；若仍失败，检查主动推送权限。

**Q26：日志文件越来越大怎么办？**
没有自动轮转；停止后改名/清空 `logs\bridge.log` 即可，见 [operations.md](operations.md)。

**Q27：可以接其它模型/执行端吗？**
可以。API 执行端兼容 OpenAI 格式（改 `api.base_url`/`model` 即可）；
新增本机执行端见 [architecture.md](architecture.md) 第 6 节。

**Q28：为什么 Python 版本要求 3.10+？**
代码使用了较新的 asyncio/类型写法与依赖版本；3.10 是保守下限，推荐 3.12/3.13。

**Q29：仓库里的 `wheels/` 为什么离线装不上？**
`wheels/` 的二进制轮子面向 **Python 3.12 / Windows x64**；其它版本会自动走在线安装，
或运行 `scripts\download-wheels.ps1` 重新下载匹配版本。
