# 安全与隐私（Security & Privacy）

> 一句话：**这个项目等于把你电脑的控制权接到一个聊天窗口上。** 便利与风险对等，
> 请先读完本文再决定开放范围。快速清单见仓库根目录 [SECURITY.md](../SECURITY.md)。

---

## 1. 威胁模型

| 角色/资产 | 风险 | 缓解 |
|---|---|---|
| **Bot Secret / Bot ID** | 泄露 = 他人可冒名连接机器人（若同时踢掉你） | 后台重置；`config.json` 不提交；权限 600 |
| **DeepSeek API Key** | 泄露 = 他人可消费你的额度 | 环境变量或本地文件；平台删除重建 |
| **能发消息给机器人的人** | = 能向你的电脑下指令 | 机器人可见范围最小化；仅本企业成员 |
| **手机 / 企业微信账号** | 被盗 = 远程控制电脑 | 手机锁屏/二次验证；不在公共设备登录 |
| **本机 DSH 凭证** | 桥接需要读取 `~/.dsh/.credentials.yaml` 生成本地鉴权 | 仅访问本机回环；不传输、不打印 |
| **日志 `logs/bridge.log`** | 含聊天内容摘要与 `chat=` 标识 | 不公开；分享前脱敏；定期清理 |
| **workspace 产出** | 可能含商业/个人信息 | 不进 Git；按需备份加密 |

> 桥接不开放任何入站端口，只主动外连企业微信与 DeepSeek，攻击面主要在「凭证 + 谁能发消息」。

---

## 2. 数据流与数据落盘

```text
手机 → 企业微信服务器 → 桥接进程（本机）→ 执行端（DSH 本机 / DeepSeek API）
                        ↓
                  logs/bridge.log（消息前 120 字 + chat 标识）
                  workspace/（任务产出文件）
```

| 数据 | 是否离开本机 | 说明 |
|---|---|---|
| 聊天文本/语音转文字 | 是（企业微信平台 + 可选 DeepSeek API） | 平台侧隐私政策由其条款约束 |
| 电脑执行结果 | 是（回传企业微信） | 只回传任务结果/文件 |
| DSH 本地凭证 | **否** | 仅本机读取，不写日志、不上传 |
| `config.json` | **否** | 仅本机读取 |

## 3. 高风险默认项（必须知情）

1. **`dsh.auto_approve=true`（默认）**
   - 行为：启动/首次用 DSH 前调用其 `settings/update`，把默认权限设为 `danger-full-access`；
   - 影响：远程任务**无需人工批准**即可执行任意操作（含读写文件、运行命令）；
   - 关闭：`"auto_approve": false`（任务会在电脑上等人工点允许）。
2. **DSH 模式可读写本机文件并回传**
   - 这是产品能力，也是数据外发通道；只给可信成员用。
3. **文件回传标记**
   - 仅 `engine=dsh` 会执行 `[[SEND_FILE:路径]]`；API 模式强制剥离（防提示注入外发本机文件）。
4. **主动推送**
   - 任务完成/长任务结果会主动发到手机；内容可能含文件路径、命令输出等信息。

## 4. 加固清单

- [ ] 机器人可见范围只勾选自己（或最小必要成员）；
- [ ] `config.json` 不进 Git、不网盘明文同步；权限仅本人可读；
- [ ] API Key 优先用环境变量；
- [ ] 不需要全权限时设 `dsh.auto_approve=false`；
- [ ] 不在公网映射桥接端口（不需要）；
- [ ] Windows 防火墙允许出站即可，入站保持默认拒绝；
- [ ] 定期轮换 Secret / API Key；
- [ ] 日志分享前脱敏，定期清理；
- [ ] 离开电脑先 `stop.cmd`；长期不用注销自启；
- [ ] 关注 DSH / 企业微信 SDK 的安全更新。

---

## 5. 泄露/事件响应

1. **Bot Secret 泄露**：企业微信后台重置 Secret → 更新 `config.json` → 重启桥接；
2. **API Key 泄露**：DeepSeek 平台删除旧 Key → 新建 → `set-api-key.cmd` 更新（无需重启）；
3. **`config.json` 被误提交到 Git**：
   - 立刻轮换全部凭证；
   - 从 Git 历史移除（`git filter-repo` 等）并强推；
   - 若仓库已公开，视为已泄露，按上面两步处理。
4. **怀疑有人冒用机器人**：查企业微信机器人日志/可见范围；重置 Secret；检查本机 `bridge.log`。

---

## 6. 隐私提示

- 日志默认记录每条消息的前 120 字与 `chat=` 标识，用于排障；
- 若你不希望留下聊天痕迹：定期清空 `logs\bridge.log`，或不要把敏感内容发给机器人；
- 截图/录屏演示时注意遮挡手机号、姓名、企业信息。
